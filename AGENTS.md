# Instruções locais do Growth Loop

Este projeto usa Next.js 15.5.16. O pacote instalado não contém o diretório
interno `node_modules/next/dist/docs/` mencionado pelo `AGENTS.md` do projeto
principal. Não crie nem edite documentação dentro de `node_modules`.

Antes de alterar APIs ou convenções do Next.js, consulte
`docs/TECHNICAL_ALIGNMENT.md`, os tipos/código da versão instalada e, como
fallback, a documentação oficial versionada do Next.js 15.
